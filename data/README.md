# Data

Benchmark datasets and precomputed partition pools are not redistributed in this public code release. The repository implements the BEGF formulation, but the paper's benchmark numbers are not regenerated by the public tests.

For a benchmark rerun, provide one record per dataset with:

```text
dataset_id,dataset,n_samples,n_features,n_classes,partition_file,labels_file,sha256,protocol
```

The partition file must contain the base-partition labels used to build `X0` for the benchmark run; the target labels are used only after filtering for external metrics. Each partition must have one label per sample and may use arbitrary label names. `begf.build_x0` converts the labels to deterministic nonempty-cluster indicator blocks.

`paper_results.csv` records the final Table 2 results for the ten datasets reported in the ICASSP 2027 paper. It reports percentages, uses the paper's dataset names and dimensions, and leaves unavailable valid outputs empty with `valid=NO`; no missing value is imputed. It is a result record and is not regenerated by the public tests.
